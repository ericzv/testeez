## Configurações Recomendadas para Geração:

- **Resolução**: 1024x768 ou 768x1024 (paisagem ou retrato conforme evento)
- **Steps**: 30-50
- **CFG Scale**: 7-9
- **Sampler**: DPM++ 2M Karras ou Euler a
- **Negative prompt sugerido**:
```
cartoon, anime, 3d render, photorealistic, bright colors, happy atmosphere, modern setting, low quality, blurry, watermark, signature, text
```

## Cores Predominantes por Evento:
- **Sangue/Dano**: Vermelho carmesim
- **Ouro/Riqueza**: Dourado escuro
- **Magia/Mistério**: Roxo/Azul
- **Morte/Maldição**: Preto/Verde doentio
- **Cura/Vida**: Azul claro/Branco
